# Windows 免安装便携包

当前默认发行版本为 v1.10.0。题库经逐组核对，从373条原题形成229道有效题；144条重复题保留为别名以保护历史引用，不物理删除。新增 `distillation.py` 和 `data/reviewed_duplicate_groups.json` 列入打包白名单；该映射为程序资料，不作为用户导入题库处理。

新刷题轮、模考抽题、题库浏览使用有效题库；旧轮仅清理未来空白重复项，保留已答、当前题及草稿。错题按题组复习并保留历史，收藏复习仍不改变错题本。整理依据和逐组审阅在模考模块的 `docs` 中。

v1.10.0统一离线包覆盖原版至v1.9.0的11个正式基线。构建时固定使用v1.9.0包内的Python、Node及site-packages，避免运行组件变化放大补丁。`release_v1100_checks.py build` 构建补丁，`verify` 实际验证升级、回滚及中断恢复。验收文件保存在本机 `归档管理/v1.10.0验收`，不上传个人测试数据。

清理后旧解压目录可能不存在。需要重建某条旧版补丁时，先从本机保留的对应正式ZIP完整解压为原目录名，再运行构建；不得用已升级目录替代原始基线。旧ZIP及校验文件不得修改。下文按版本记录的是历史行为，当前默认构建以本段为准。

入口是原生 Windows 窗口，三个模块继续使用原有业务代码和界面。支持 Windows 10/11 x64；依赖 Windows 自带 .NET Framework/Windows PowerShell 及现有 Edge/Chrome，不需要队友安装 Python、Node.js、pip 或其他包。

构建时只复制明确允许分享的内容：三 AI 程序、模考试题源文件、网站清单、知识点静态导航和 11 份 PDF。不会复制原有 API 配置、模考数据库、管理员密码、会话密钥、导入暂存或网站检测/人工审核历史。原模块文件不被改写。

发布包中的 `runtime/python` 是独立解释器和标准库，不是依赖原电脑绝对路径的虚拟环境。使用 `python._pth` 隔离外部 Python 设置，随包携带 Flask、openpyxl 等依赖；MarkupSafe 使用其自带纯 Python 实现。`runtime/node/node.exe` 直接运行现有 CJS 程序，不携带整套开发工具。

构建只对复制后的 PowerShell 文件进行两项适配：解释器路径改为包内运行组件、清除原电脑专用的默认 GPT 代理。脚本以 UTF-8 BOM 保存，兼容 Windows PowerShell 5.1 的中文读取。

## 重新生成

构建机器需要 Python 3.11+、已有 Windows x64 Python/Node 运行组件和 .NET Framework C# 编译器。默认查找本机 Codex 缓存中的运行组件，应用依赖默认取自项目 `.venv/Lib/site-packages`，也可通过参数明确指定。

```powershell
# 在项目根目录，用可用的 Python 运行：
python packaging/build_portable.py

# 输出已存在时会拒绝覆盖，避免破坏使用过的目录。新版本请指定新目录：
python packaging/build_portable.py --output "交付文件/AI信息素养工具箱_新版本"
```

`--python-home` 指定完整运行组件目录，`--node` 指定独立 `node.exe`，`--packages` 指定包含所需模块的 site-packages。构建不安装软件、不读取 API 密钥，也不会调用 AI。Node.js 官方许可证保存在 `license-node.txt`，Python 和第三方包许可证随相应文件保留。

输出包括完整文件夹、ZIP、ZIP 的 SHA-256 校验文件；包内 `build-manifest.json` 列出每个文件的大小和 SHA-256。用户运行数据均保存在解压目录中，移动整个目录可保留；先退出程序再备份。

## 验证

```powershell
python -m unittest discover -s packaging/tests -v
python packaging/verify_portable.py "交付文件/AI信息素养工具箱_Windows免安装版.zip" --destination "交付文件/验证记录/新建中文路径 空格"
python packaging/run_regression.py "交付文件/验证记录/新建中文路径 空格/AI信息素养工具箱_Windows免安装版" --logs "交付文件/验证记录/功能回归"
```

`verify_portable.py` 必须使用空目录：从 ZIP 重新解压、逐项核对文件哈希，将 PATH 限制为 Windows 系统目录，并故意设置错误的外部 Python/Node 配置，再验证原生入口 `--check`、两个服务、退出清理、初始化题库、完整 10 题练习和成绩保存、三路本地模拟 AI 接口及 11 份 PDF 链接。不会访问收费 AI 接口。`--check` 是可供支持诊断的正式程序入口，主窗口也提供同一项「环境自检」。

`run_regression.py` 将测试复制到一次性的解压副本，用包内解释器运行全部 26 项 AI 测试、30 项模考与刷题测试和 13 项检测测试。真实 Edge 检查只访问受控本地页面，使用独立临时浏览器资料目录；执行沙箱可能阻止浏览器连接，这种情况下需在允许独立浏览器运行的环境重测，不应修改业务检测代码来适应沙箱。

`tests/LauncherUiCheck.cs` 通过真实 WinForms 控件验证慢任务不会阻塞窗口，并在屏幕外生成入口截图。将此测试宿主编译到一次性解压副本中（使应用根目录指向该副本），传入工具箱 EXE 和截图输出目录即可。

统一入口使用 Windows Job 与按 PID 的进程树清理；只管理自己启动的进程。模考继续支持局域网，端口自动选择，并在窗口给出当前可复制地址；每台电脑运行的独立副本不自动同步成绩。

验证副本会产生测试账号、成绩与日志，不能再次用于分发。最终发送给队友的始终是未经使用的原始 ZIP。

## 离线升级包

最初已发出的无版本号发行包视为 `1.0.0`，原 ZIP 与原发行目录保留不变，作为可复现的升级基线。自 `1.1.0` 起，清单带版本号，完整发行包默认输出到带版本号的新目录；主窗口显示版本，并允许选择外部升级 EXE 后退出当前实例。

```powershell
python packaging/build_portable.py --version 1.1.0
python packaging/build_update.py --base "交付文件/AI信息素养工具箱_Windows免安装版" --new "交付文件/AI信息素养工具箱_Windows免安装版_v1.1.0" --output "交付文件/AI信息素养工具箱_离线升级包_v1.0.0到v1.1.0"
```

后续每次更新先生成新的干净完整版，再与对应的已发布干净版本比较。升级 EXE 内嵌变更文件和前后版本清单，通过 SHA-256 验证文件完整性；它不依赖系统 Python/Node、不联网、不请求管理员权限。此校验用于发现文件损坏，不等同于发行者数字签名。分发应使用发布者提供的原始升级 ZIP。

更新程序核对安装目录的原清单及全部程序哈希；新增文件已有冲突、版本不匹配、原文件被手动改动或程序仍在运行时拒绝替换。它与工具箱使用同一个按安装目录生成的互斥锁，整个升级与验证期间保持锁定，避免新实例进入。

更新前备份变更程序文件，以及三个固定可写目录：AI `data`、模考 `data`、检测 `reports`。更新不会携带或直接覆盖这些目录中的个人配置/数据库/审核记录；模考的两个公开题库源文件是允许更新的例外。题库源文件变化时，`upgrade_data.py` 利用现有去重导入增量添加题目，不删除旧题或改写已有题目编号。网站资源不得复用旧 ID 指向不同网址，以免历史审核错配。

操作日志保存在原目录 `update-backups/<时间与唯一编号>/journal.json`。程序替换前写入 `applying` 状态；验证中为 `validating`；成功后最后提交新版本清单并写入 `committed`。普通失败自动恢复程序和数据；再次运行升级 EXE 时，会先恢复此前遗留的未完成事务。备份包含个人数据，不可随新版发行包分享。

数据恢复前先持久化 `restoring-data` 状态，重启后继续恢复完整快照，避免将半恢复目录当成完整数据。一般升级中断的恢复只还原程序文件，保留当前最新个人数据，并在 `update-backups/recovery-<唯一编号>` 额外保存副本；副本与事务备份并列，减少 Windows 路径长度。如果是数据回滚过程本身被中断，则保留当前残留副本后续完原快照恢复。新版工具箱会阻止在上述未完成阶段启动。验证子进程由 Windows Job 管理，更新进程退出时一并终止，避免与后续恢复并发写数据库。

```powershell
python packaging/verify_offline_update.py --old "交付文件/AI信息素养工具箱_Windows免安装版.zip" --update "交付文件/AI信息素养工具箱_离线升级包_v1.0.0到v1.1.0" --destination "交付文件/离线升级验证/全新中文路径 空格"
```

验证从已发出的原 ZIP 开始，用其自带运行组件创建测试账号、一次完整练习、自建题、Windows DPAPI 加密测试密钥和审核记录。验证损坏包/错误版本/运行中拒绝、实际失败自动回滚、持久化未完成事务恢复、升级后记录保持、重复升级拒绝、原生入口重新启动，以及新增题目重复导入的幂等性。所有测试数据仅在验证副本中生成。

v1.9.0 自定义答题时间
个人练习、团队练习、个人对抗、团队对抗和完整模拟总时限均可单独设置。整数分钟，0表示不限时，范围0至1440。
模考首页展开自定义设置，填写后点击保存时间。时间设置与题数分值分别保存；按登录账号保留。
已开始的试卷和模拟固定开局时限；完整模拟阶段受到本场总时限约束，总时限0则无限制。旧历史截止时间保持不变。
默认个人/团队对抗仍为5/15分钟，两种练习默认不限时，模拟总时限默认20分钟。
