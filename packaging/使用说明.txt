一、怎么给队友使用
1. 发送整个「AI信息素养工具箱_Windows免安装版_v1.10.0.zip」。
2. 队友先将压缩包全部解压到桌面、文档或其他可写文件夹。
3. 双击文件夹中的「AI信息素养工具箱.exe」。不要在压缩软件内直接运行。
4. 不需要安装 Python、Node.js，不需要运行任何安装命令，也不需要管理员权限。

适用于 Windows 10/11 的 64 位电脑（x64）。使用 Windows 自带的窗口组件和浏览器；
浏览器检测使用电脑上的 Microsoft Edge 或 Google Chrome。请保留解压后的完整目录，
不能只把一个 exe 文件发出去。可把整个目录移动到其他可写位置，数据随目录保留。

二、三个模块

本版题库已蒸馏为229道有效题。随机刷题、模考抽题和题库浏览均使用整理后的题库；
旧题号、历史成绩、错题和收藏保留。已有刷题轮会保留当前题、已答题和草稿，
只清理后面尚未作答且没有草稿的重复项。新一轮即可使用完整整理结果。

【三 AI 同查】
点击「配置 API」，分别填写 GPT、千问、DeepSeek 的密钥与接口地址，再点击「打开」。
密钥由各自使用的 API 平台提供；API 调用需要联网，可能由 API 平台计费。
密钥使用 Windows 当前用户加密保存。更换电脑或 Windows 用户后需要重新填写。
默认不填写 GPT 代理；只有确实使用本机代理时，才在答题窗口填写实际地址。
外部接口地址、模型支持与网络条件由所用平台决定。缺少配置或网络错误会显示在对应列。
队友可继续使用原工具支持的环境变量配置，已有环境变量优先于窗口中保存的配置。
答题窗口新增「思考档位」按钮，分别选择三个模型的思考深度，保存后下次答题生效。
v1.4.1 修复已有思考设置时再次保存失败的问题，可以连续修改、保存并在重开后恢复。
GPT 支持低/中/高/更高/最高；千问支持关闭/低/中/更高；DeepSeek V4.1 Flash 支持关闭/低/高/最高。
思考模式通常会增加等待时间和 API 用量；档位与所用密钥独立保存，不需要重填密钥。
桌面按钮选择的档位优先；直接运行脚本时可用对应 REASONING_EFFORT 环境变量覆盖。

四、遇到问题
1. 确认已完整解压，没有只复制 exe；将程序放在有写入权限的文件夹。
2. 点击主窗口「环境自检」，程序会验证包内组件及两个本地服务，不会调用收费 AI 接口。
3. 自检后点击「数据与日志」，查看 logs\startup-check.json 及服务日志。
4. API 不通：核对密钥、接口地址、网络和所填代理。原作者电脑上的代理不适用于队友。
5. 网站浏览器检测失败：确认电脑上有可正常运行的 Edge 或 Chrome。
6. 运行中的服务端口会自动选择，主窗口提供当前地址，无需手动修改端口。
7. 如果使用校园统一管控电脑，应用运行仍受该电脑已有的管理策略约束。

此便携版保留原三个模块的功能，新增统一入口和包内运行组件。
当前发行包不包含原作者的 API 密钥、管理员密码、账号、成绩或人工审核记录。

原工具箱会退出，在升级窗口点击「开始升级」。也可以先关闭工具箱，直接双击升级 EXE。

升级失败会自动恢复；若升级中断，再运行同一个升级程序恢复。

v1.9.0 自定义答题时间
个人练习、团队练习、个人对抗、团队对抗和完整模拟总时限均可单独设置。整数分钟，0表示不限时，范围0至1440。
模考首页展开自定义设置，填写后点击保存时间。时间设置与题数分值分别保存；按登录账号保留。

默认个人/团队对抗仍为5/15分钟，两种练习默认不限时，模拟总时限默认20分钟。
