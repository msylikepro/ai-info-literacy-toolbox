# 淘汰赛模考：使用说明

## Windows 启动

安装 Python 3.10 或更新版本后，双击 `start.bat`。首次启动会自动安装依赖、创建 SQLite 数据库并导入题库。浏览器打开 <http://localhost:5000>；同一局域网的队友访问 `http://这台电脑的局域网IP:5000`。Windows 防火墙若提示，请允许专用网络访问。启动窗口需要保持打开。

首次启动的管理员账号为 `admin`，随机密码保存在 `data/admin_credentials.txt`。也可在首次启动前设置环境变量 `ADMIN_PASSWORD` 指定密码，此时不生成密码文件。请勿把数据库、密码文件或 `.secret_key` 分享给队员。

三位队员分别注册；一人创建队伍并把邀请码发给另两人。可选择不限时的“个人练习”“团队练习”，或限时对抗与完整模拟。每卷固定 10 题，按 6 道单选、2 道多选、2 道判断的顺序呈现；只能向前作答，跳过会提示确认。个人卷答对 +2 分、答错 -1 分、未答 0 分，满分 20 分；团队卷答对 +4 分、答错 -1 分、未答 0 分，满分 40 分。个人对抗限时 5 分钟，团队对抗限时 15 分钟；对应练习模式不限制时间。交卷反馈逐题显示服务端记录的作答用时；提前交卷时尚未进入的题目，以及启用该功能前的旧试卷，会显示“无用时记录”。

创建或加入队伍后即可开始团队对抗、团队练习和完整模拟，无须等满三人。完整模拟为本场每位队员各出一份个人卷，全部完成后任一队员启动共用团队卷。单人、双人、三人模拟分别为 20、30、40 题，满分 60、80、100 分，最多 20 分钟；同分时比较本场所有个人用时之和加团队用时。提前提交会保留实际用时；超时按服务端截止时间交卷。旧试卷及其历史成绩保留原评分规则。

## 全题库刷题与错题本

登录后在控制台点击「全题库刷题 / 继续上次」。每轮将开始时题库里的所有题目随机排序，一题只出现一次；不限时，无需组队，也不要求题型达到模考的 6/2/2 配额。选好答案后点击「提交答案」，立即显示对错、正确答案、来源及题库中已有的解析；缺少解析时明确提示，不生成额外解析。查看反馈后进入下一题，最后一题提交后显示本轮统计，可开始新一轮。

每次选项变化自动保存草稿，提交后保存作答结果与当前进度。看到保存成功提示后，可以刷新、退出登录或关闭工具箱；重新启动后登录同一账号，回到原题或尚未离开的答案反馈。进度保存在本机模考数据库，不依赖浏览器缓存。不同账号独立；不同电脑各自运行的副本不自动同步。一轮开始后新导入的题目进入下一轮，不打乱本轮次序。

刷题答错自动进入「我的错题本」，记录错误次数、上次错答、正确答案、解析及时间。可筛选待复习、已掌握、全部历史，点击「重练待复习错题」随机重练当前待复习题目；错题重练单独保存进度，不打断全题库刷题。后续答对将标记「已掌握」并保留错误历史，再次答错会恢复为待复习。

刷题记录与模考计分分别保存，不参与原有个人/团队成绩。升级增加刷题及重复题映射所需的数据表，原有账号、题目、成绩与题目编号保留。当前错题本记录本功能上线后的刷题与错题重练错答，不回填旧模考试卷。

## 浏览全部题库与关键词检索

训练控制台新增「浏览题库」入口。列表包含全部已导入的有效题目，每页 20 题，可翻页查看；同一题的格式重复版本合并展示，后续导入的新题也会自动出现。输入题干或选项中的关键词进行检索，英文不区分大小写，多个关键词用空格分隔并同时匹配。清空检索可点击「查看全部」。

每张题目卡片显示题干和全部选项，答案默认隐藏。点击该题的「显示答案」查看正确答案、已有解析和来源，再次点击可收起，不影响其他题目的答案显示状态。浏览和检索只读取题库，不更改题目、收藏、刷题进度、错题本或模考成绩。

## 收藏题目与独立复习

全题库刷题和错题重练的题目上方提供「收藏本题」按钮，再次点击可取消收藏；提交答案前后均可操作。控制台和刷题页均可进入「我的收藏集」。收藏按本机账号存入原模考数据库，关闭、重新登录或重开工具箱后仍保留，不同账号各自独立。

收藏集逐题显示原题和选项，可以正常提交判题，也可以不作答直接点击「显示答案」，支持收起答案、重新作答、上一题/下一题和题号跳转。点击「移出收藏」只取消本人的收藏标记，不删除题库题目。收藏集仅用于自由复习：作答和查看答案都不增加或掌握错题，不改变刷题进度、题序或模考成绩。

## 预置题库蒸馏与升级保留

v1.10 将原来显示的 373 道预置题进一步蒸馏为 **229 道有效题**。题库浏览、新刷题轮、模考抽题及库存计数使用同一份有效题库。判断重复时比较题干、全部选项和正确选项的内容，不只比较答案字母；保留标准年份、检索词、否定词、公式及选项内容不同的版本。逐组审阅依据见 [题库蒸馏审阅记录](docs/题库蒸馏审阅记录_2026-10-20.md)，冻结映射在 `data/reviewed_duplicate_groups.json`。

升级保留全部 373 条原题、原题编号、来源和旧指纹，通过重复映射减少重复出题。旧模考试卷及成绩保持原样，收藏仍能打开原题。未完成刷题轮只剔除未来尚未作答且没有草稿的重复题；已答内容、当前题目与反馈、未提交草稿和断点保留，因此升级中的旧轮题数可能高于 229。完成后新开一轮使用有效题库。

错题本按同题组显示一次并汇总错误次数，最后一次错答仍对应原来的选项顺序。重练每组只出一题；答对后同组标记已掌握，再次答错同组恢复待复习。原来的逐题错答历史保留。

## 导入题库

管理员登录后在“管理题库”上传 JSON、CSV 或 XLSX，先预览新增、重复、异常，再确认导入。JSON 可为题目数组或 `{ "questions": [...] }`。字段：`type`（`single`、`multi`、`judge`）、`stem`、`options`（JSON 数组，或以 `|` 分隔的文字；CSV/XLSX 也可用 A、B、C、D 列）、`answer`（如 `A`、`AC`）、`source`、`module`、`original_id`、`explanation`。中文列名“题型、题干、选项、答案、来源、知识模块、原始编号、解析”也受支持。去重忽略选项顺序，但保留选项文字不同的版本。

后续上传已审阅的预置版本，也会通过冻结映射识别重复。未知题目只沿用原有 NFKC、连续空白折叠和选项内容比较；不删除中文内部空格、句末符号或空括号，不解码 HTML 标签和实体原文，不推断同义词，以保护检索式和代码题。相同题干和选项若答案内容冲突，会计入异常，原始导入内容保留在管理员页面的「待核验导入题」，不会覆盖现有答案。重复上传不增加有效题数。

预置题库来源：[89757-creater/ai-info-literacy-quiz](https://github.com/89757-creater/ai-info-literacy-quiz) 与 [Ziv-ZHI/ai-infolit-competition](https://github.com/Ziv-ZHI/ai-infolit-competition)。来源标签保留仓库名称，题目真实性未逐题核验，不能据此认定为正式浙江省赛真题。单项练习至少需要 6 道单选、2 道多选、2 道判断题；完整模拟四卷互不重复，至少需要 24 道单选、8 道多选、8 道判断题。不足时明确提示，不会补造题目。

## 测试

在本文件夹运行 `../.venv/Scripts/python.exe -m unittest discover -s tests -v`。

蒸馏专项回归为 `tests/test_distillation.py`，覆盖新库 229 题、373 题旧库迁移、导入幂等与冲突、旧轮草稿/反馈保留、收藏兼容及错题同组掌握。真实旧库克隆验证脚本为 `tests/verify_distillation_clone.py`：只读备份源库，在临时克隆执行迁移，校验完成后清除临时克隆；不会修改源库或查询口令字段。验收汇总见 `docs/题库蒸馏克隆迁移验收_2026-10-20.json`。

## 文件分类

- `start.bat`：双击启动网页模考平台。
- `app.py`、`importer.py`、`distillation.py`、`requirements.txt`：平台程序、题库导入、重复映射与依赖清单。
- `templates/`、`static/`：网页和样式。
- `data/`：题库、原有成绩数据库、管理员账号文件与登录配置。
- `tests/`：平台的现有验证文件。

本板块继续使用上一级的 `.venv` 环境，启动脚本已同步调整。原有题库、成绩、账号与配置保留。
