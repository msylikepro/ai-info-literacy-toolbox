# 本机网址检测工具

目标：在本机匿名访问196个已提取的网址，记录可访问性、速度和登录提示，并保留判断依据。

实现：Node.js内置HTTP服务提供本地界面；HTTP(S)请求检查状态、跳转、首字节时间和内容类型；Windows已安装Edge的独立匿名浏览器配置通过CDP检查动态页面，记录DOM就绪时间和可见登录/验证提示。最多4个检测任务并发，同域名导航间隔不小于700毫秒。整个工具放在独立目录，不依赖原练习平台。

边界：不输入密码、不尝试登录、不绕过验证码或访问控制。公开文件可直接读取；公开网页的首页可浏览不证明核心功能可匿名使用。疑似登录仅为提示，登录按钮、Cookie同意按钮、403和验证码不能单独判定账号必需。速度来自本机当前网络单次测量；浏览器加载有上限，超时不直接等同网站永久失效。

文件：checker.cjs负责HTTP和判断；browser.cjs负责Edge/CDP；server.cjs负责运行队列、保存和本地API；public/负责界面；启动检测工具.bat直接在前台运行Node.js；tests/负责受控网页测试；reports/保存结果。
