# 50知识点检验：分类说明

从 `01_网址清单/50个知识点_网址清单.html` 查阅知识点相关网址；需要检查网址和记录人工审核时，双击 `02_网站检测工具/启动检测工具.bat`。

「知识点资料」导航使用网站正式或常用名称，支持中文名、英文名、别名、域名和知识点检索。政策、报告等具体内容保留明确标题，并标出所属网站。名称数据及核对来源保存在 `04_网址导航网站/knowledge-links/data/site_names.json`；重新生成导航时同步更新网站检测工具的名称，资源编号和网址保持一致，保留历史审核对应关系。

| 分类 | 用途 | 推荐入口 |
| --- | --- | --- |
| 01_网址清单 | 按50个知识点查看网址；另存Markdown和去重TXT | [知识点网址清单](01_网址清单/50个知识点_网址清单.html) |
| 02_网站检测工具 | 自动检查网址、筛选异常、记录人工审核 | 双击 `启动检测工具.bat`；[使用说明](02_网站检测工具/使用说明.md) |

| 04_网址导航网站 | 网址导航网页、构建源文件与数据 | [网址导航](04_网址导航网站/knowledge-links/dist/index.html) |
| 05_原始资料与过程 | 原始JSON、网页、候选PDF、截图、提取与整理脚本 | 通常无需打开；用于追溯来源和重新生成资料 |

## 检测记录放在哪里

- 最新数据：`02_网站检测工具/reports/latest.json`。
- 现有报告：[检测报告](02_网站检测工具/reports/检测报告.html)。
- 人工勾选记录：`02_网站检测工具/reports/manual-audits.json`，已完整保留。
- 首次原始检测：`02_网站检测工具/reports/首次原始检测.json`。

现有报告是之前的检测结果，本次分类没有重新联网检测。关于旧报告的判断限制，见工具使用说明。

## PDF与历史版本说明

PDF文件名、索引和内容保留原样；原资料说明中提及的两份中文PDF尚未下载，本次仅进行分类。打包文件是整理前的版本；当前使用请优先打开分类目录内的文件。

原始资料中的 `site-package`、`site-package-final` 属于先前网页打包记录，保留在过程资料中；日常使用的网址导航入口在 `04_网址导航网站`。相关生成脚本的输出路径已同步到本次分类目录。
