## 恢复方法

在工作区打开 PowerShell。下列命令使用保留的 v1.9.0 便携版 Python，不需额外安装环境。恢复目标必须是尚不存在的新文件夹，原工作区不会被覆盖。

```powershell
& '.\交付文件\AI信息素养工具箱_Windows免安装版_v1.9.0\runtime\python\python.exe' -B '.\packaging\local_archive.py' verify '.\归档管理\清理前完整归档_2026-10-20.zip'
& '.\交付文件\AI信息素养工具箱_Windows免安装版_v1.9.0\runtime\python\python.exe' -B '.\packaging\local_archive.py' restore '.\归档管理\清理前完整归档_2026-10-20.zip' --destination '.\归档管理\清理前恢复副本'
```

如已将运行组件迁至其他位置，将命令中的 Python 路径替换为现有便携版内的 `runtime/python/python.exe`。恢复完整测试副本需要约 22.4 GB 空间。

## 今后维护

1. 使用者更换版本前，先备份已使用工具箱的整个文件夹。
2. 源码修改完成并验证后提交 GitHub；不要强行提交被忽略的个人数据。
3. 每个正式版本保留原始 ZIP 及校验文件，旧 ZIP 用作离线升级基线，同版本不重新发布不同内容。
4. 完整版和升级包通过白名单构建，检查不含个人配置后，再上传到 Releases。
5. 清理记录在本机 `归档管理`。已删除的临时副本可以从完整归档恢复；有效源文件、个人数据和正式旧 ZIP 保留。
