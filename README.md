# AI＋信息素养工具箱

面向 Windows 的三个工具：三 AI 同查、模考与刷题、知识点资料和网址检测。

v1.10.0 将原373道题整理为229道有效题。重复题保留原题号和历史引用，新刷题轮、模考抽题及题库浏览使用整理结果；未完成轮保留当前题、已答题和草稿。未知近似题保守保留，防止误合并检索式、年份或代码题。

普通使用者请在[版本下载页面](https://github.com/msylikepro/AI-/releases/tag/v1.10.0)选择「Windows 免安装完整版」，完整解压后双击 `AI信息素养工具箱.exe`。刷题、模考和本地资料可以离线使用；AI 提问与网站检测需要联网。首次使用自行填写 API 配置。源码下载包不包含 Python、Node.js 运行组件。

已有版本可使用离线升级包，解压到原工具箱文件夹之外，运行 `双击开始升级.bat`，选择原工具箱所在文件夹。升级会备份并保留账号、API 配置、成绩、刷题断点、错题、收藏及手动网址。请保管自己的 ZIP 和个人数据，避免分享已经使用过的工具箱目录。

| 模块 | 功能 | 说明 |
| --- | --- | --- |
| [三 AI 同查](01_三AI同查/README.md) | GPT、千问、DeepSeek 同时回答；文字、题目截图、思考档位 | API 接口须支持所配置的模型与图片输入 |
| [模考与刷题](02_淘汰赛模考/README.md) | 个人与团队模考、随机刷题、错题本、收藏、题库浏览检索 | 支持自定义题数、分值与答题时间 |
| [知识点资料](03_50知识点检验/README.md) | 网址检索、添加和修改网址、检测与人工审核、PDF 资料 | 手动修改及审核记录在本机保存 |

本仓库用于源码归档与版本维护，不包含个人 API 密钥、数据库、管理员口令、学习记录、浏览器缓存或完整本机备份。题库和参考资料保留原来源说明，未授予第三方资料新的许可；题目答案仍需结合原始资料核对。

维护与打包见 [packaging/README.md](packaging/README.md)，本地备份和恢复见 [归档与恢复说明](docs/归档与恢复.md)。本机日常入口为 `使用导航.html`，交付用 ZIP 保存在本机 `交付文件`，完整备份及清理记录保存在本机 `归档管理`。
